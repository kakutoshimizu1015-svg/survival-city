# SURVIVAL CITY — 金缶争奪戦

本番: https://kakutoshimizu1015-svg.github.io/survival-city/

元の公開版のゲーム本体を使い、遊びやすさと立体的な景観に合わせて標準マップを作り直した版です。キャラクター・AP・ラウンド制・アイテム・ミニゲームを引き継ぎ、勝利条件とCPUの目標を金缶争奪へ変更しています。

## 元のゲームから引き継いだ内容

- キャラクター15人と元のスキン、各キャラクターの能力・特殊スキル。
- ミニゲーム15種類。独立したミニゲーム画面と、盤面のイベントからの起動。
- 2〜8人、CPUの弱め・普通・鬼畜、チーム対戦と設定項目。
- 2個のサイコロでAPを獲得する仕組み、ゾロ目、移動と行動のAP消費。
- 缶・ゴミ・買取・バイト・ショップ・陣地・維持費・武器・カード・戦闘と復活。勝敗計算は下記の金缶方式に変更。
- NPC、天候、昼夜と視界、元のマンホールワープ。
- 標準マップは新しい「街めぐり」48マス。従来の小・中・大（12 / 48 / 75マス）も選択できます。

元のJavaScriptモジュールへ、再生成可能な限定的フックで金缶ルールを接続しています。`classic.html` は従来の勝敗計算です。オンラインはホストで購入を検証し、金缶・対人キル・結果を同期します。実ブラウザでの対戦検証はローカル・CPU、通信はホスト/ゲスト境界の模擬検証です。

## 新しい広域ボードと3地域

34マス版の外周26マスと2本の連絡路を残し、内側に14マスの寄り道を加えた48マスです。テント街の縦横の路地、店舗の間を抜ける細道、噴水そばで四方向に分かれる公園があります。分岐は9か所で、残り39マスは進路選択なし。すべての隣接マスは論理座標で距離1、描画上は12単位間隔を保ちます。

マンホールは3か所から6か所に増加。テント街・商店の裏・公園にも設け、元の1 APワープで他のマンホールへ移動できます。移動・CPU・イベント処理は従来どおりです。

- **スラム街**: 青ビニールテント8張、ごみ山、一斗缶焚火、錆びたトタン板とフェンス。路地は道を選んで縦横に抜けられます。
- **商業地区**: コンビニ・ゲームセンター・飲食店・デパート・武器屋・カードショップ。店舗の間を通る裏路地を追加。
- **高級住宅街**: タワマン、白い邸宅、高級車、装飾街灯、噴水公園。公園の中も実際の移動ルートです。

境界は曲線状の入り組んだ地面に変更。コンビニをスラム側に、テントを商業側に置き、タワマンと邸宅も外側へ広げています。22か所の主要な敷地のうち20か所が周回路の内側です。背景には高架橋、走る3両編成の電車、2層の遠景ビル26棟と丘を配置。動きを減らす設定では電車を静止させます。

Three.jsの正投影カメラで、高さ・影・重なりを描きます。地域間の坂道と立体の円形マスを維持。プレイヤーは元の絵のビルボード、NPCは立体のロウポリゴンモデルです。建物の陰になるマスには操作用の補助表示を出します。通常プレイでは角度と倍率を固定した近距離の視点で、手番の駒（CPUを含む）を滑らかに追います。ゴミ収集車・パトカーの移動は一時的に優先して映し、到着を見せてから手番の駒へ戻します。同時移動は順番に映し、巡回中は視点を奪いません。「マップ巡回」に切り替えると、1本指／左ドラッグで移動、2本指の開閉／ホイールでズーム、2本指の左右移動で回転、2本指の上下移動で角度調整ができます。PCでは右ドラッグ（またはShift＋ドラッグ）で回転・角度を変え、ダブルクリックで全景に戻せます。「プレイに戻る」または巡回ボタンにフォーカス中のEscapeで自分の駒の視点に戻ります。巡回中はカード・行動ボタンとマスの選択を無効にします（CPUやゲーム進行を一時停止する機能ではありません）。

元のクリック対象をカメラと地面の高さに合わせ、分岐・地下道・罠・NPC移動先などの選択を元の処理へ渡します。武器の扇形射程も新マップの座標に合わせて投影します。WebGLが使えない端末は同じ48マスを元の2D盤面で遊べます。`classic.html` では変更前の2D版と46マスを利用できます。

## 立体NPC

ゴミ収集車は白い運転席・錆びた青い圧縮荷台・6輪タイヤ・後部回収口を持つ大型車に変更。パトカーには停車中の警察官を添え、厄介なおじさんはベストと杖、ヤクザはスーツとサングラス、闇金は鞄、仲間はリュック、野良動物は元の絵に合わせたネズミの群れで表現します。

移動方向に車体と体が向き、タイヤ・手足・尻尾が動きます。警告灯はゆっくり明滅し、動きを減らす設定では静止します。NPCの位置・遭遇効果・撃破・復活・夜の視界は元の処理に従います。警察官は既存のパトカーと同じNPCの演出で、新しい敵の判定は増やしません。大型車と同じマスのプレイヤーはカメラ側にずらして表示します。

## 駒に付く装備とアイテムの演出

ショッピングカート・リヤカー・リュック・ヘルメット・盾・安全靴・身代わり人形・自転車・折りたたみ自転車・雨具を、元の装備状態に応じてロウポリゴンで表示します。駒の移動やカメラ回転に追従し、消費・破損・期限切れ・死亡で外れます。

武器は照準中に構え、攻撃確定時に拳銃・ショットガン・レーザー銃・レンガ・バット・釘バットなどを表示。レンガは放物線を描き、バットは振り、銃は反動と弾の演出が出ます。照準パネルは駒を隠しにくい画面端に置き、元のドラッグ操作も利用できます。キャンセルでは攻撃演出を出しません。飲食物やエナジードリンクなどは、使用が受理された時だけ短く表示します。単なる購入・廃棄・AP不足では使用演出を出しません。

装備の効果や寿命、カード・AP消費、攻撃対象、ダメージは元のゲーム処理のままです。動きを減らす設定では、武器や使用アイテムを静止表示してから消します。プレイヤー本体の元の絵は保持しています。

## 絵で選ぶショップと街のイベント

ショップを、左に店員・店内のピクセルアート、右に商品棚・選択した商品の絵と説明・カート・会計を置く画面に変更。武器、装備、食料などで絞り込めます。購入・売却・品替え・所持金・在庫・手札上限・職業割引は、元のショップの状態とコールバックを使用します。

投資話、自販機の下、贈り物、野良犬の4つの選択イベントには、それぞれ状況のピクセルアートを用意しました。元の選択肢・確率・報酬・ダメージ・AP消費を保持。スマホでは絵と操作欄を縦に並べます。ショップのTabキーによるフォーカス移動、Escapeでの退出、イベントのキーボード選択にも対応します。

`src/art/` の場面絵はこのゲーム用に生成したオリジナル素材です。商品は `src/pixel-item-art.js` の小さなピクセルイラストで表示します。

## スマホ操作

縦画面ではページ全体のスクロールを止め、上部にHP・AP・所持金、中央にマップ、下部に直近の結果と行動ボタンを固定表示します。手札・ランキング・ログは同じ画面内のパネルで開きます。マスはタップした場所だけを説明します。手札や長い履歴のパネル内はスクロールできます。分岐は大きな道選択ボタンでも選べ、マスの説明はタップして閉じるまで表示します。行動・カード・分岐は元のコントロールへ委譲し、CPU・オンライン権限・AP計算を維持します。

`scripts/verify-mobile-ui.cjs` は320〜430pxの縦画面、ページのスクロール、マス説明、四方向の分岐/AP、手札、イベント結果、巡回中の操作制限とPC表示への復帰を検証します。

スマホの固定配置を維持したまま、元のキャラクター画像・職業名・HPバー・各種ステータスと装備アイコン、茶色と金色のパネルを表示します。上部は常に自分の情報だけを表示し、他プレイヤーはランキングから確認します。マップは端末の画素密度に応じ最大2倍（描画幅1800px・高さ1400px以内）で描き、キャラクター画像の縮小処理を調整しています。

スマホの通常マップは表示領域の約2/3に拡大。全行動ボタンを下部に表示し、「その他の行動」を開く手間をなくしました。小型画面では全行動の44px以上のタップ領域を確保するため、マップの高さが約57%になります。ランキングは金缶×3＋対人キル×2の得点順で、同点は所持P順です。マス一覧ボタンは廃止し、タップしたマスだけを小さく説明します。巡回操作は左上に縮小し、拡大縮小・左右回転・俯角調整（約22〜66度）に対応。通常プレイに戻ると角度をリセットします。`verify-mobile-map-controls.cjs` で画面比率、ランキング、単一マス説明、巡回操作、分岐/APを検証します。

モバイルのマップ内AP表示を復元。ラウンド・天気は左上、その下に小さな巡回切替を置き、巡回中のカメラ操作ボタン群はジェスチャー操作に置き換えています。

マスは `src/tile-visuals.js` の種類別カラーと共通アイコンで表示します。物理マス・遮蔽物越しのマーカー・分岐カードで同じ絵柄を使い、分岐でもマス本来の効果を隠しません。分岐中はマップと選択肢の番号を対応させます。
巡回中の2本指入力はフレームごとにまとめ、ピンチ・左右移動・上下移動から主な操作を判定して指を離すまで固定。ピンチの基準位置を指の中心に置き、意図しない回転・傾きと小さな指ぶれを抑えます。この操作改善に続き、下記の金缶ルールを導入しました。


## 金缶争奪戦

- 金缶1個＝3点、対人キル1回＝2点。同点は所持P、両方同じなら同順位。チーム戦はメンバーの得点とPを合計します。
- 金缶は公開された1か所で10P。到着するとマップ下部の「金缶を買う」で購入できます。AP不要、通常の空き缶とは別枠です。
- 購入後は次ラウンドに別地点へ出現。最終ラウンドには新規出現しません。目的地の「場所」で巡回視点をその場所へ向けます。
- 対人キルで相手から最大1個奪います。金缶0個の相手でもキル2点。NPC討伐は既存のP/カード報酬を維持し、対人キルに含めません。
- NPC・毒などの環境死は、その場に金缶1個を落とします。他プレイヤーも回収できます。反撃・プレイヤーの罠による撃破は相手プレイヤーに加点します。
- 復活無敵は維持。金缶モードでは死亡時の追加P没収とランダム装備喪失を撤廃（攻撃によるP奪取と通常資源のドロップは継続）。デス減点はありません。
- 部門別の表彰は廃止し、終了後は直接結果画面へ進みます。50P加算・資源価値・陣地価値を勝利点へ足しません。
- CPUは回復・資金調達を行いつつ、購入地点や落ちた金缶へ向かい、射程内の金缶所持者や倒せる相手を優先して攻撃します。

再生成: `python3 scripts/build-card-balance.py` → `python3 scripts/build-gold-engine.py` → `python3 scripts/build-original-runtime.py`。元ストアの入力は `scripts/vendor/original-network-store.js` です。差分フックはすべて置換対象が一意であることを確認します。
検証: `node --test tests/gold-rules.test.js`、ローカルHTTPサーバー上で `node scripts/verify-gold-cans.cjs`。勝敗・購入・奪取・ドロップ・CPU実手番を確認します。経済価格10P・配点3:2は初期バランスで、今後の対戦結果に合わせて調整します。


## 出現位置・説明・結果演出

- 金缶は到達可能な候補の中から、距離の差が極端でない最大16マスを抽選。直近3か所の購入地点を避け、固定の巡回順にはしません。
- NPC7種の初期位置を毎回抽選し、開始位置のプレイヤーやNPC同士の重なりを避けます。ゲームごとの進路の重みと分岐ごとの抽選で巡回経路を変化させ、道路の矢印・工事通行止めを守ります。決定はホスト側の状態に保持します。
- 分岐候補に効果と必要APを表示。マップ巡回中も、PCのクリック・スマホのタップでそのマスだけの説明を確認できます。ドラッグは説明を開きません。
- ステータス枠の見切れを解消。スマホ上部に装備アイコンを表示し、プレイヤー一覧はアイコン・数値・単位が途中で折り返さない形にしました。
- 金缶の得点計算を保ったまま、虹色の結果演出と元の4種類の優勝メッセージを復元。動きを減らす設定では虹色の背景を静止表示します。

## スマホの情報配置とショップ

自分のステータスのすぐ下に、丸みのある「手札・ランキング・ログ」タブを表示。CPUの手番でも自分の情報と手札を確認できます。行動は下部にすべて表示します。マス詳細はPCとスマホで同じパネル・色・文字サイズを使います。

ショップは「商品・個数を選ぶ → 選択内容を確認 → 最下部で購入／売却」の順。各商品の＋／−で直接個数を調整でき、合計と確定ボタンは常に下部に残ります。価格・在庫・所持金・手札上限の計算は元ルールを維持します。

## 金缶ルールに合わせたカード整理と武器供給

- 順位・逆転条件は個人の「金缶×3＋対人キル×2」、同点は所持Pで統一。両方同じなら同順位で、同率最下位も使用可能。チームの勝敗は従来どおり合算し、カードの条件は個人順位です。
- 大暴落: 最下位限定、0AP、HPを半分消費し、敵のPを半減。味方は対象外。裏取引での反射は維持します。
- 下剋上: 最下位限定、1AP。自分より上位の敵のうち最上位から最大10Pを奪取。旧30P差条件を廃止。相手に奪えるPがない場合は手札もAPも消費しません。
- 行政の見落とし: 最下位限定、0AP、8P獲得。使用時に所持PがNaNになる不具合も修正。
- 出現対象から除外: 缶泥棒(4)、領土挑戦状(5)、今日の運勢(9)、野良猫の導き(10)、密かなバイト(11)、宝くじ当選(14)、ニセ情報(43)。少額資金カードの重複と、金缶争奪から遠い陣地専用妨害を整理。生活資源・陣地収入・回復・装備・移動・防御は残します。
- 初期手札・ショップ・NPC報酬・イベント・ミニゲーム報酬・ドロースキル・CPUハッキングで出現対象を統一。IDと画像は互換性のため残し、クラシック版では従来のカードを利用できます。
- 初期手札3枚の先頭はバット。ショップは重複のない6品で、レンガ3P・バット4Pを固定入荷。基本武器は各プレイヤー各ラウンド4個まで、次ラウンドに補充。再入店や品替えでは補充されません。その他の在庫は従来仕様です。
- 営業マンは2P引き、最低2Pとし、買って即売却する無限利益を防止。CPUも同価格・同在庫上限で基本武器を購入します。キル点・武器威力は変更していません。
- 手札・ショップ・ルール内カード一覧を同じ効果説明に統一。通常版のヘルプとチュートリアルは同じ金缶ルールブックを表示。リヤカーの陣地収入2倍が説明だけで未適用だった点も、金缶モードで修正しました。

検証: `node --test tests/*.test.js`、`node scripts/verify-card-balance.cjs`、`node scripts/verify-gold-cans.cjs`、`BASE_URL=http://localhost:8003 node scripts/verify-pixel-scenes.cjs`。実カードの判定・効果・消費、同率最下位、チーム、購入上限と補充、旧モード、ゲストのホスト委譲を検証しています。
