# SURVIVAL CITY — 街めぐりボード

確認用サイト: https://survival-city-street-preview.heartyotter17.chatgpt.site

元の公開版のゲーム本体を使い、遊びやすさと立体的な景観に合わせて標準マップを作り直した版です。キャラクター・AP・ラウンド制・CPU・アイテム・ミニゲームの処理は元のゲームを使用します。

## 元のゲームから引き継いだ内容

- キャラクター15人と元のスキン、各キャラクターの能力・特殊スキル。
- ミニゲーム15種類。独立したミニゲーム画面と、盤面のイベントからの起動。
- 2〜8人、CPUの弱め・普通・鬼畜、チーム対戦と設定項目。
- 2個のサイコロでAPを獲得する仕組み、ゾロ目、移動と行動のAP消費。
- 缶・ゴミ・買取・バイト・ショップ・陣地・維持費・武器・カード・戦闘・復活・勝敗計算。
- NPC、天候、昼夜と視界、元のマンホールワープ。
- 標準マップは新しい「街めぐり」48マス。従来の小・中・大（12 / 48 / 75マス）も選択できます。

ルールとCPUを別実装で再現せず、元のJavaScriptモジュールをそのまま読み込みます。元ゲームのオンライン連携コードも残っていますが、この更新での動作確認はローカル・CPU対戦が対象です。

## 新しい広域ボードと3地域

34マス版の外周26マスと2本の連絡路を残し、内側に14マスの寄り道を加えた48マスです。テント街の縦横の路地、店舗の間を抜ける細道、噴水そばで四方向に分かれる公園があります。分岐は9か所で、残り39マスは進路選択なし。すべての隣接マスは論理座標で距離1、描画上は12単位間隔を保ちます。

マンホールは3か所から6か所に増加。テント街・商店の裏・公園にも設け、元の1 APワープで他のマンホールへ移動できます。移動・CPU・イベント処理は従来どおりです。

- **スラム街**: 青ビニールテント8張、ごみ山、一斗缶焚火、錆びたトタン板とフェンス。路地は道を選んで縦横に抜けられます。
- **商業地区**: コンビニ・ゲームセンター・飲食店・デパート・武器屋・カードショップ。店舗の間を通る裏路地を追加。
- **高級住宅街**: タワマン、白い邸宅、高級車、装飾街灯、噴水公園。公園の中も実際の移動ルートです。

境界は曲線状の入り組んだ地面に変更。コンビニをスラム側に、テントを商業側に置き、タワマンと邸宅も外側へ広げています。22か所の主要な敷地のうち20か所が周回路の内側です。背景には高架橋、走る3両編成の電車、2層の遠景ビル26棟と丘を配置。動きを減らす設定では電車を静止させます。

Three.jsの正投影カメラで、高さ・影・重なりを描きます。地域間の坂道と立体の円形マスを維持。プレイヤーは元の絵のビルボード、NPCは立体のロウポリゴンモデルです。建物の陰になるマスには操作用の補助表示を出します。通常プレイでは角度と倍率を固定した近距離の視点で、手番の駒（CPUを含む）を滑らかに追います。ゴミ収集車・パトカーの移動は一時的に優先して映し、到着を見せてから手番の駒へ戻します。同時移動は順番に映し、巡回中は視点を奪いません。「マップ巡回」に切り替えると、地域ボタン・全景・現在地・回転・拡大縮小・ドラッグ移動・ピンチを利用できます。「プレイに戻る」または巡回ボタンにフォーカス中のEscapeで自分の駒の視点に戻ります。巡回中はカード・行動ボタンとマスの選択を無効にします（CPUやゲーム進行を一時停止する機能ではありません）。

元のクリック対象をカメラと地面の高さに合わせ、分岐・地下道・罠・NPC移動先などの選択を元の処理へ渡します。武器の扇形射程も新マップの座標に合わせて投影します。WebGLが使えない端末は同じ48マスを元の2D盤面で遊べます。`classic.html` では変更前の2D版と46マスを利用できます。

## 立体NPC

ゴミ収集車は白い運転席・錆びた青い圧縮荷台・6輪タイヤ・後部回収口を持つ大型車に変更。パトカーには停車中の警察官を添え、厄介なおじさんはベストと杖、ヤクザはスーツとサングラス、闇金は鞄、仲間はリュック、野良動物は元の絵に合わせたネズミの群れで表現します。

移動方向に車体と体が向き、タイヤ・手足・尻尾が動きます。警告灯はゆっくり明滅し、動きを減らす設定では静止します。NPCの位置・遭遇効果・撃破・復活・夜の視界は元の処理に従います。警察官は既存のパトカーと同じNPCの演出で、新しい敵の判定は増やしません。大型車と同じマスのプレイヤーはカメラ側にずらして表示します。

## 駒に付く装備とアイテムの演出

ショッピングカート・リヤカー・リュック・ヘルメット・盾・安全靴・身代わり人形・自転車・折りたたみ自転車・雨具を、元の装備状態に応じてロウポリゴンで表示します。駒の移動やカメラ回転に追従し、消費・破損・期限切れ・死亡で外れます。

武器は照準中に構え、攻撃確定時に拳銃・ショットガン・レーザー銃・レンガ・バット・釘バットなどを表示。レンガは放物線を描き、バットは振り、銃は反動と弾の演出が出ます。照準パネルは駒を隠しにくい画面端に置き、元のドラッグ操作も利用できます。キャンセルでは攻撃演出を出しません。飲食物やエナジードリンクなどは、使用が受理された時だけ短く表示します。単なる購入・廃棄・AP不足では使用演出を出しません。

装備の効果や寿命、カード・AP消費、攻撃対象、ダメージは元のゲーム処理のままです。動きを減らす設定では、武器や使用アイテムを静止表示してから消します。プレイヤー本体の元の絵は保持しています。

## 絵で選ぶショップと街のイベント

ショップを、左に店員・店内のピクセルアート、右に商品棚・選択した商品の絵と説明・カート・会計を置く画面に変更。武器、装備、食料などで絞り込めます。購入・売却・品替え・所持金・在庫・手札上限・職業割引は、元のショップの状態とコールバックを使用します。

投資話、自販機の下、贈り物、野良犬の4つの選択イベントには、それぞれ状況のピクセルアートを用意しました。元の選択肢・確率・報酬・ダメージ・AP消費を保持。スマホでは絵と操作欄を縦に並べます。ショップのTabキーによるフォーカス移動、Escapeでの退出、イベントのキーボード選択にも対応します。

`src/art/` の場面絵はこのゲーム用に生成したオリジナル素材です。商品は `src/pixel-item-art.js` の小さなピクセルイラストで表示します。

## 起動と以前の版

`npm start` でローカルサーバーを起動し、`http://localhost:8000` を開きます。

現在の入口は元のゲーム設定画面につながります。ルール・状態の構造が異なるため、以前の簡易版の途中セーブを元ルールへ変換しません。以前の保存キーは削除せず、`quick.html` から簡易版を続けられます。`classic.html` は元の2D版です。元ルール版のゲーム中セーブ機能は追加していません。

## 実装と検証

- `assets/index-CRnOnW6E.js` と既存の依存モジュール: 元の配布ファイル。ゲーム処理を保持。
- `scripts/build-original-runtime.py`: 標準マップを差し替え、元のUIに投影用属性・武器描画フック・キーボード操作を加えた `assets/original-city-runtime.js` を生成。各置換箇所の一意性を検証。
- `src/city-board-map.js`: 48マス・分岐9か所の接続、イベント種類と入り組んだ地域境界。ゲームごとに独立した配列を生成。
- `src/city-scenery.js`: 地域が混在する22敷地と立体の建物・テント・装飾。
- `src/city-backdrop.js`: 高架橋、3両編成の電車、遠景の建物と丘。
- `src/pixel-scenes.js`: 元のショップと選択イベントに接続するReactの表示部品。
- `src/pixel-item-art.js`: 商品棚・選択肢のピクセルイラスト。
- `scripts/verify-pixel-scenes.cjs`: カメラ固定／巡回、購入・売却・在庫・割引・上限、全4イベント、PC・スマホを実ブラウザで検証。
- `src/player-items.js`: 装備・武器・消耗品の立体モデルと表示管理。
- `scripts/verify-player-items.cjs`: 元のカード使用による装備、追従、消費解除、照準キャンセル、武器ダメージ、消耗品、AP不足、後片付けを検証。
- `scripts/preview-player-items.cjs`: 通常モーションでのレンガ・バット・拳銃とPC・スマホ表示を確認。
- `src/npc-models.js`: 7種類のNPCの立体モデル、車輪・歩行・尻尾・警告灯の演出。
- `scripts/verify-npc-models.cjs`: 立体モデル、移動、消滅と再出現、夜の視界、動きを減らす設定、画面回転とスマホ表示を確認。
- `src/original-world.js`: 地域別の建築、地面、道路、影、コマ、カメラと投影。
- `src/original-bridge.js`: 元のストアを購読し、元のマス・プレイヤー操作位置を更新。ルールの代替実装は含まない。
- `src/original-city.css`: 表示の調整。元の操作・ミニゲーム・モーダルは引き継ぐ。
- `tests/city-board-map.test.js`: 全マスへの到達、辺の距離、分岐数、イベント種類・ワープ・新規ゲームの独立性を検証。
- `scripts/verify-district-board.cjs`: 標準マップの起動、直進、全分岐の両経路、坂道の投影、地域の装飾、4画面幅と電車の移動を実ブラウザで確認。
- `scripts/verify-original-rules.cjs`: 15キャラクターと15ミニゲーム、4マップ、CPU設定と実行、分岐とAP消費、3地域、スマホ表示を実ブラウザで検証。

公開用リポジトリでは静的ファイルは `dist/` 内にあります。GitHub上の元の公開サイトにはpushしていません。

夜は青みのある環境光に切り替わり、一斗缶焚火の局所照明、窓明かりと地面への光、店舗のネオンが点灯します。車両カメラはラウンド終了処理中の待ち時間も保持し、収集車からパトカーへ直接切り替えます。

## スマホ操作

縦画面ではページ全体のスクロールを止め、上部にHP・AP・所持金、中央にマップ、下部に直近の結果と行動ボタンを固定表示します。手札・状態・ログ・マス情報は同じ画面内のパネルで開きます。手札や長い履歴のパネル内はスクロールできます。分岐は大きな道選択ボタンでも選べ、マスの説明はタップして閉じるまで表示します。行動・カード・分岐は元のコントロールへ委譲し、CPU・オンライン権限・AP計算を維持します。

`scripts/verify-mobile-ui.cjs` は320〜430pxの縦画面、ページのスクロール、マス説明、四方向の分岐/AP、手札、イベント結果、巡回中の操作制限とPC表示への復帰を検証します。
